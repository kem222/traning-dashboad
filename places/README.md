# ふたりの行きたいところ

彼女と「行きたいね」と話した場所を、思いついた瞬間に LINE か Web からメモして、
**旅行（泊まり）/ おでかけ（日帰り）/ デート（カフェ・ごはん）** の大きさ別と **地図** で見返すためのアプリ。

```
LINE（ふたりのトーク or Bot）──┐                       ┌─▶ Googleスプレッドシート
                               ├─▶ Google Apps Script ─┤
Web（places/index.html）───────┘                       └─▶ Claude（AI。任意）
```

- 名前から自動で地図の位置を補完
- AIを有効にすると：まとめて書いた・貼り付けたメモを1件ずつに分けて、**大きさ**と**ジャンル**に整理。「まとめて」でジャンル別の整理と次に行く候補の提案

- `index.html` … スマホ向けWebページ（リスト / 地図 / 行った）
- `gas/Code.gs` … バックエンド（Apps Script）。Web API と LINE Bot の両方を担当

設定をしなくても `index.html` を開けば、**その端末の中だけ**で使えます（お試し用）。
ふたりで共有＆LINEから追加するには、以下を1回だけやってください（30分くらい）。

---

## 1. スプレッドシート + Apps Script を用意する

1. Googleスプレッドシートを新規作成（名前は何でもOK。例：「行きたいところ」）
2. メニュー **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身を全部消して、`gas/Code.gs` の中身を貼り付けて保存
4. 左の **⚙ プロジェクトの設定 → スクリプト プロパティ** に以下を追加

   | プロパティ | 値 |
   |---|---|
   | `APP_TOKEN` | 適当な長いランダム文字列（Webページ用の合言葉） |
   | `LINE_WEBHOOK_KEY` | 別の適当な長いランダム文字列 |
   | `APP_URL` | WebページのURL（下の「3」で決まったら入れる） |
   | `LINE_ACCESS_TOKEN` | 「2」で取得するLINEのトークン |
   | `ANTHROPIC_API_KEY` | （任意）「2.5」で取得する Claude の APIキー |

5. エディタ上部の関数選択で `setup` を選んで **実行** → 権限の確認が出るので許可
   （スプレッドシートに `places` シートができればOK）
6. 右上 **デプロイ → 新しいデプロイ** → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - デプロイして出てくる `https://script.google.com/macros/s/.../exec` をメモ

> コードを貼り替えたときは「デプロイを管理 → 編集 → バージョン：新バージョン」で更新してください（URLは変わりません）。

## 2. LINE Bot を作る

1. [LINE Developers](https://developers.line.biz/console/) にLINEアカウントでログイン → プロバイダー作成
2. **Messaging API チャネル** を作成（LINE公式アカウントが一緒にできます）
3. チャネルの **Messaging API設定** タブで
   - **チャネルアクセストークン（長期）** を発行 → スクリプトプロパティ `LINE_ACCESS_TOKEN` に貼る
   - **Webhook URL** に
     `（1-6のURL）?src=line&key=（LINE_WEBHOOK_KEYの値）` を設定し、**Webhookの利用：オン**
     （「検証」ボタンはApps Scriptの仕様でエラー表示になることがありますが、実際に送って返事が来ればOK）
   - **グループトーク・複数人トークへの参加を許可する**：オン
4. [LINE Official Account Manager](https://manager.line.biz/) の応答設定で **応答メッセージ：オフ / Webhook：オン**
5. QRコードからBotを友だち追加

### 使い方（2通り）

**A. ふたりのトークにBotを招待する（おすすめ）**
彼女とのトークを「グループ」にしてBotを招待。普段の会話は無視され、次のときだけ追加されます。

```
行きたい 〇〇珈琲
行きたい 旅行 箱根の〇〇旅館
＋ おでかけ すみだ水族館
（GoogleマップのURLを貼る）           ← 合図なしでも追加
（LINEの「位置情報」を送る）
```

**B. Botと1対1でトーク**
送ったものは全部追加されます。Instagram・食べログ・Googleマップの「共有 → LINE → Bot」が一番ラク。

| 送る内容 | 動き |
|---|---|
| `行きたい ○○` / `＋ ○○` | 追加（AIなし：2行目以降はメモ） |
| `行きたい` ＋ 箇条書き・文章・トークの貼り付け | **AIあり**：行き先を1件ずつ分けて、ジャンルも付けて追加 |
| 先頭に `旅行` `おでかけ` `カフェ` | 大きさを指定（なければ名前から自動判定） |
| URL | サイトのタイトルを名前にして追加 |
| Googleマップのリンク / 位置情報 | お店の名前と正確な位置で追加 |
| `リスト` | 大きさ別の一覧を返信 |
| `まとめて` / `まとめて 雨の日` | **AIあり**：ジャンル別に整理＋「次に行くなら」を提案 |
| `行った ○○` | 行ったリストに移動 |
| `ヘルプ` | 使い方 |

返信はすべて無料枠（応答メッセージ）なので、月の通数制限は気にしなくてOK。

## 2.5 AI（Claude）を有効にする（任意・おすすめ）

1. [Claude Console](https://platform.claude.com/) にサインアップし、支払い方法を登録（使った分だけの後払い/前払いクレジット）
2. **API Keys** でキーを作成 → スクリプトプロパティ `ANTHROPIC_API_KEY` に貼る
3. 使いすぎが心配なら Console の **Limits** で月の上限金額を設定しておくと安心
4. Apps Script で「デプロイを管理 → 編集 → 新バージョン」で更新

- 1回の追加・まとめは数秒〜10秒ほど。ふたりでメモする程度なら費用はごくわずかです
- モデルを変えたいときはスクリプトプロパティ `CLAUDE_MODEL` に指定（例：より安く速い `claude-haiku-5-5`）
- キーを入れなくてもアプリは動きます（そのときはキーワードで自動分類）
- 既にあるデータにジャンルを付けるには、エディタで `fillGenres` を1回実行

## 3. Webページを公開する

このリポジトリで GitHub Pages を有効にすると
`https://<ユーザー名>.github.io/traning-dashboad/places/` で開けます
（Settings → Pages → Branch を選んで Save）。

1. ページを開いて右上 **⚙︎** → 名前・API URL（1-6）・合言葉（APP_TOKEN）を入れて保存
2. 設定画面に出る **「パートナー用の設定リンク」** を彼女にLINEで送る → タップするだけで同じリストが見られる
3. スマホで「ホーム画面に追加」しておくとアプリっぽく使えます
4. スクリプトプロパティ `APP_URL` にこのページのURLを入れると、LINEの返信にリンクが付きます

## できること

- **大きさ別 / ジャンル別 を切り替え**：🧳旅行・🚗おでかけ・☕デート、または 🍰カフェ・🍽ごはん・🍷お酒・🏯観光・🌿自然・🎡遊び・♨️温泉宿・🛍買い物・🎆イベント
- **✨ AIでまとめる**（AIあり）：条件（「今月の週末」「雨の日」など）を入れると、整理して次の候補を提案
- **地図**：全部をピンで表示（色と絵文字で大きさが分かる）。ピンから Googleマップ / お店のサイト へ
- **近い順**：現在地から近い順に並べ替え（「今近くにあるカフェどこだっけ」用）
- **自動で位置を補完**：名前から位置を検索。違っていたら「編集」で検索し直すか地図をタップ
- **行った！**：日付とひとことを残して「行った」タブへ（あとから振り返り用）
- データはスプレッドシートにあるので、直接編集・バックアップも可能

## 注意

- Webページの合言葉を知っている人は誰でも読み書きできます。設定リンクはふたりの間だけで共有してください。
- 位置の自動検索は名前があいまいだとズレることがあります（「渋谷のあのカフェ」など）。
